NFT Match — сервис для коллекционеров Telegram-подарков. В его основе алгоритм MatchV2: он разбирает каждую модель на цвета и по ним подбирает подходящие фоны, находит визуально похожие модели и собирает монохромы — сочетания, где модель и фон выдержаны в одном цвете.

Диаграмма цветов моделей

Светлота: весь диапазон
Коллекция:
Выбери коллекцию
Модель:
Сначала выбери коллекцию
Цветовой профиль модели — размер круга и % показывают долю каждого цвета
Клик по цвету исключает его из поиска
