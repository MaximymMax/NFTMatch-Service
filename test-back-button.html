Проблема с кнопкой "Назад" решена

✨ Что было исправлено

Теперь при переходе по реферальной ссылке (например, ?startapp=api) параметры автоматически удаляются из URL после обработки. Это предотвращает циклические переходы при нажатии кнопки "Назад".

🧪 Как проверить исправление

  1. Нажмите кнопку "Открыть страницу API" ниже
  2. Вы будете перенаправлены на страницу API
  3. Нажмите кнопку "Назад" в браузере
  4. ✅ Вы вернётесь на главную страницу БЕЗ повторного перенаправления на API

📝 Технические детали

Функция clearDeepLinkParams() использует window.history.replaceState() для удаления параметров deep linking из URL без перезагрузки страницы. Это гарантирует, что при возврате назад URL уже не содержит этих параметров.
