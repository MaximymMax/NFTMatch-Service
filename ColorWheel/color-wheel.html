Монохромы Тематики Похожие

NFT MATCH — сервис для подбора подарков, фонов и коллекций по цвету в Telegram. Мы анализируем изображение каждой модели, выделяем доминирующие цветовые кластеры в перцептивном пространстве Lab и сравниваем их по цветовой дистанции, чтобы находить похожие модели, подходящие фоны и монохромные сочетания.

Диаграмма цветов моделей

Светлота: весь диапазон
Коллекции:
Все коллекции

Поиск моделей по цвету

Один цвет — покажем ближайшие модели. Несколько — только те, где есть все сразу.

% — доля этого цвета в модели, ближе к 100% — точнее совпадение.
